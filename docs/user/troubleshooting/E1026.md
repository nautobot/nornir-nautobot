# E1026 Details

## Message emitted:

`E1026`: A Ruckus Smartzone failed with an authentication issue: `{push_result[0].result}`

## Description:

Netmiko failed to authenticate to the device with the provided credentials.

## Troubleshooting:

Check that the authentication credentials are correct.

## Recommendation:

Check that the authentication credentials are correct such as verifying the username and password in Nautobot secrets is what you expect
